# GeoFS Community Add-ons

A curated collection of essential open-source enhancements for [GeoFS](https://www.geo-fs.com), focused on upgrading visuals, aircraft availability, and custom airline liveries.

## Included Add-ons

### 1. Free HD Textures
* **What it does:** Replaces low-resolution default ground textures and environment details with higher-definition imagery to dramatically improve visual fidelity during low-altitude flight and approaches.
* **Why use it:** Enhances immersion without requiring paid subscriptions or heavy performance trade-offs.

### 2. GeoFS LiverySelector
* **What it does:** A unified livery handler and user interface add-on that aggregates hundreds of custom community paint jobs (including packs from Spice9, Ariakim Taiyo, and Iuhairways). 
* **Key Features:**
  * In-game `[L]` menu or toolbar integration to swap airline liveries on the fly.
  * Star/pin your favorite aircraft textures for quick access.
  * Supports custom `airline.json` files for virtual airline fleets.

### 3. Extra Vehicles
* **What it does:** Injects additional community-made aircraft models and specialty vehicles not natively present in the standard GeoFS roster.
* **Why use it:** Expands your hangar with custom airliners, business jets, and utility craft.

---

## Installation

These scripts are designed to run via userscript managers like **Tampermonkey**, **Greasemonkey**, or **Violentmonkey**.

1. Install a userscript browser extension (e.g., [Tampermonkey](https://www.tampermonkey.net/)).
2. Download or copy the target `.user.js` script files from this repository.
3. Import or create a new script in your manager, paste the code, and save.
4. Open or reload [GeoFS](https://www.geo-fs.com)—the add-on panels and assets will load automatically.
